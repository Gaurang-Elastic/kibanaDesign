## Context Engine

An isolated Kibana example plugin for prototyping how agents discover, prioritize, and
assemble working context.

Run only this example from the Kibana repository root:

```sh
yarn start --plugin-path=examples/context_engine
```

Then open `/app/contextEngineExample` on the local Kibana server.

Because this is an example plugin, it is not loaded by normal Kibana development or
production builds.
